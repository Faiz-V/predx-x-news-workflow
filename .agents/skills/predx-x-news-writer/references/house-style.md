# PredX house style

This profile is distilled from the user's bilingual reference archive. Later entries in that archive represent newer practice and carry more weight than earlier entries. Reproduce the durable writing behavior, not individual sentences, errors, unsupported claims, promotional language, or outdated facts.

## Core voice

- Lead with the news, not an abstract introduction.
- Sound like a fast, informed operator explaining why a development matters.
- Use concrete figures, named actors, procedural stages, and observable consequences.
- Move from fact to explanation to impact. Keep interpretation measured and traceable to evidence.
- Prefer a decisive final observation, short verdict, specific question, or genuine checkpoint over a generic summary.
- Use audience-facing questions selectively when they name the actual decision or uncertainty. Do not append an unscoped “你怎么看？” or engagement bait by habit.

## Default information density

Every usable post must contain:

1. the strongest verified development;
2. the driver, mechanism, or material context;
3. the consequence for the account's audience.

Add scale, comparison, uncertainty, or the next checkpoint when the source supports it. If the cause is not verified, write the known context and explicitly preserve the gap.

This is the compact explained-news target:

- not a headline plus two facts;
- not a full article or background memo;
- one important idea per content block;
- one sentence per block by default; a second sentence is an exception, not the rhythm.

## Format envelopes

Count only the post body, excluding account labels, sources, timestamps, and editorial notes.

### Explained news — default

- Chinese: target 170–260 non-whitespace characters; acceptable 150–320.
- English: target 380–650 characters; acceptable 320–800.
- Structure: 4–6 content blocks separated by blank lines.
- Use for policy, macro, crypto infrastructure, technology, geopolitics, and consequential sports news.

### Fast breaking update

- Chinese: target 140–220 characters; acceptable 120–270.
- English: target 300–520 characters; acceptable 260–650.
- Structure: 4–5 blocks.
- Use only when the event is genuinely new and the available facts are still limited.

### Data stack

- Chinese: target 150–260 characters; acceptable 130–300.
- English: target 340–620 characters; acceptable 280–750.
- Structure: one hook, 3–5 short metric lines or blocks, then one consequence.
- Use only when each number materially changes interpretation.

### Claim versus response or live diplomacy

- Chinese: target 190–300 characters; acceptable 170–340.
- English: target 430–720 characters; acceptable 380–850.
- Structure: 5–6 blocks covering claim, response, verified common ground, consequence, and unresolved point.

### Standard X override

Use a 280-weighted-character English post only when the user explicitly asks for a standard short X post. Do not silently compress a reference-style request into this mode.

## Paragraph rhythm

- Make the first block a short title-like sentence. Use `JUST IN:` for a genuinely new verified development; otherwise prefer an objective direct fact, named actor, number, or concise contrast.
- Give each block one job: event, evidence, driver, effect, constraint, or next checkpoint.
- Aim for one sentence in each block. If a block needs two sentences, keep both on the same job and ensure multi-sentence blocks are rare.
- Keep the opening roughly within 36 non-whitespace Chinese characters or 90 English characters when the facts allow. Keep later Chinese blocks near 30–65 characters and English blocks near 60–140 characters.
- Keep the ending useful, but do not force it into a forecast: choose among the next decision, data release, vote, match, confirmation, constraint, limited implication, specific audience question, short verdict, or no separate ending.
- Reserve `接下来`, `下一步`, and `Next` for a genuinely observable catalyst. If the final block works after deleting that transition, delete it.
- Do not force every post to five blocks. A batch should visibly vary between 4–6 blocks when the evidence allows.

## Reference traits to preserve

- News-forward headline or first line.
- Specific numbers early when they carry the story.
- A clear explanation of why the development happened or what mechanism connects the facts.
- A limited market, political, sporting, or technological consequence.
- Short, direct transitions such as “This means,” “The key point,” or “Next watch” only when natural.
- Occasional `JUST IN:`, contrast, data stack, audience-facing question, or short punchline—never all at once and never across every account.

## Traits not to copy

- Unsupported certainty such as “will undoubtedly” when evidence only supports possibility.
- Treating allegations or forecasts as confirmed facts.
- Repetitive or unscoped “What do you think?”, “你怎么看？”, or “Stay tuned” endings; a question must name the real subject or tradeoff.
- Direct prediction-market, betting, wallet-profit, or product promotion unless the user explicitly requests it.
- Two extremes: a source card with no narrative, or an essay containing every available background detail.

## Compression test

Before translating, test the Chinese draft:

1. Remove a sentence. If the reader loses the event, driver, consequence, or essential uncertainty, restore it.
2. If removing a sentence changes nothing, delete it.
3. If a paragraph contains two unrelated jobs, split or cut it.
4. If the post feels short, add a verified mechanism, scale, comparison, or next checkpoint—not filler.
5. If it feels long, remove history and secondary detail before cutting the core causal chain.
6. If several blocks contain two or more sentences, rewrite them as one sentence each before changing the block count.
7. Read only the final block from several drafts. If they could all begin with `接下来`, `下一步`, or `Next`, change the ending function rather than swapping synonyms.
